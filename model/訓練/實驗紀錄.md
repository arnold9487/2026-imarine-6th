# 實驗紀錄

## 實驗 1:zoom-in 特寫增強(2026-07-16)

**假設**:真實照片零樣本表現差,主因是「尺度 gap」(合成圖破損只佔畫面 2~5%,真實照片多為特寫)。
**做法**:`make_closeups.py` 從 train split 每個 damage 框生成 2 張隨機裁切(1.6~5 倍窗口),共 6,470 張特寫併入訓練(train 7,912 → 14,382 張);`scale` 0.5→0.8、`mosaic` 1.0→0.5,其餘同基線。

### 結果

| 指標 | 基線 damage_yolo11s | zoom 版 damage_yolo11s_zoom |
|---|---|---|
| 合成 val:damage mAP50 | (見 runs/damage_yolo11s) | 0.790(P 0.933 / R 0.749) |
| 合成 val:container mAP50 | — | 0.995 |
| 真實 82 張有破:框到 damage | **48 張(58.5%)** | 41 張(50.0%) |
| 真實 82 張有破:框到 container | 64 張 | 36 張 |
| 真實 3 張沒破:誤框 | 2 張 | 1 張 |

逐張比較:兩版都框到 32、只有基線框到 16、只有 zoom 版框到 9、都沒框到 25。
抽樣檢視「新增命中」與「丟失命中」的照片,**兩邊都是全景照**——不是「特寫變好、全景變差」的分工,而是兩個模型各自抓到不同子集。

### 結論(假設被推翻)

1. **尺度不是主要瓶頸**:把破損放大給模型看,零樣本命中率反而 58.5%→50%。主導 gap 更可能是**材質/外觀域差**(渲染圖的平滑表面 vs 真實鏽蝕紋理)——特寫反而放大了渲染與實拍的紋理差異,讓模型更依賴合成外觀。
2. **container 辨識大幅退化**(64→36):特寫子集裡 container 框都是「裁切後蓋滿整張圖」的退化框,佔了訓練資料 45%,稀釋了完整貨櫃輪廓的監督訊號。
3. **兩版模型互補**:聯集命中 57/82(69.5%)。若 demo 需要,可雙模型並跑取聯集,但這是 workaround 不是解法。

### 下一步選項

- **A(治本,原規劃 Phase 4)**:真實照片微調。零樣本純合成有天花板,材質 gap 只有真實資料能補。82 張篩選後照片 + 標注工作區已就緒。
- **B(消融實驗)**:只加特寫、不動 mosaic/scale,重訓一次分離變因(確認退步來自 mosaic 減半還是特寫資料)。
- **C(改良特寫)**:特寫子集加強力品質退化(模糊/噪點/JPEG 失真)遮蔽渲染平滑感;container 退化框改為捨棄。
- 簡報角度:這個「假設→實驗→推翻→修正方向」的過程本身就是誠實的研究敘事,可直接用。
