# 訓練說明(RTX 5070)

## 一次性環境安裝

RTX 5070 是 Blackwell 架構(sm_120),**PyTorch 必須裝 CUDA 12.8 以上的版本**,
直接 `pip install torch` 在 Windows 會裝到 CPU 版,務必照下面指令。

在 PowerShell 執行(venv 建在 D 槽,不佔 C 槽):

```powershell
# 1) 建 venv(用你既有的 Python 3.12)
py -3.12 -m venv D:\Arnold_chun_yen\container_damage\.venv

# 2) 啟用
D:\Arnold_chun_yen\container_damage\.venv\Scripts\Activate.ps1

# 3) 裝 GPU 版 PyTorch(CUDA 12.8,支援 RTX 5070)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

# 4) 裝其餘套件(albumentations 會讓訓練自動加模糊/灰階等增強,建議裝)
pip install ultralytics albumentations matplotlib

# 5) 驗證 GPU 有被抓到(應印出 True 和 RTX 5070)
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

> 用完要離開 venv 就輸入 `deactivate`。

## 執行順序(都在本資料夾 `辨識模型\訓練\` 下)

```powershell
# Step 1:建資料集(一次即可,約 1~3 分鐘;硬連結不佔額外空間)
python build_dataset.py

# Step 2:訓練(RTX 5070 估 1.5~3 小時,60 epochs、有提前停)
python train.py

# (可選)之後想重畫圖:
python plot_metrics.py
```

## 備註

- **類別**:axis/concave/dentado/perforation 已在 build_dataset.py 合併為單一 `damage` 類。
- **切分**:沿用 SeaFront 官方 train/val,唯一一個跨切分的場景已整組歸 train(避免同場景洩漏)。
- **Macro F1**:取 ultralytics 每 epoch 的各類別平均 precision/recall(即 macro),以 2PR/(P+R) 計算;圖上會標出最佳值與其 epoch。
- 訓練中斷想續訓:`train.py` 裡 `model.train(..., resume=True)` 或重跑會產生新的 `damage_yolo11s2` 資料夾。
- VRAM 不夠(很少見)就把 `batch=-1` 改成 `batch=8`。
